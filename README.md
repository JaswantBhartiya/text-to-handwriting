# Text to Handwriting Generator ✍️



An intuitive web app that converts plain text into realistic, customizable handwritten documents. Designed to streamline creating handwritten notes, assignments, and documents directly from your browser.

## ✨ Key Features

- **Instant Conversion:** Real-time text-to-handwriting rendering as you type.

- **Customization Options:**

  - Multiple handwriting font styles.

  - Ink color selection (Blue, Black, Red, Green).

  - Page formats (Rule-lined paper, blank canvas, margin lines).

  - Adjustable font size, letter spacing, and line spacing.

- **Export Formats:** Download generated notes directly as high-resolution PNG images or multi-page PDFs.

- **Responsive Layout:** Works seamlessly across desktop and mobile browsers.



## 🛠️ Built With

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)

- **Canvas / PDF Libraries:** html2canvas, jsPDF



## ⚙️ Quick Start (Local Setup)



1. Clone the repository:

   git clone https://github.com/jaswantbhartiya/text-to-handwriting.git

   cd text-to-handwriting



2. Run locally:

   Open index.html directly in your browser, or start a local server:

   npx serve .



## 🌐 Deploying to GitHub Pages



1. Go to your repository Settings tab.

2. Select Pages from the left sidebar.

3. Under Branch, select main (or master) and click Save.

4. Your site will be published at https://jaswantbhartiya.github.io/text-to-handwriting/.
